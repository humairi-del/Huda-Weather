# إصلاح الإحصاءات الرسمي فقط — ٧ نوفمبر ٢٠٢٦

إصدار مأذون من المالك لتفعيل قياس الصفحات وحده على hada-weather.com عبر GitHub main ثم Cloudflare Workers Builds. أُنشئ من main bddd4a3؛ لا يدمج التصميم أو إصلاحات الراصد أو أي فرع معاينة. نقطة الرجوع backup-main-before-analytics-20261107 والإعدادات وبصمات النسخة الفعلية في PRODUCTION-BASELINE-20261107.json.

## فرق التشغيل المحدد

إضافة public/analytics.js، ومرجع تحميل واحد له في head، والسماح المحدود لنطاق static.cloudflareinsights.com في script-src وcloudflareinsights.com في connect-src. قيد المضيف يمنع تشغيل الملف على workers.dev أو أي معاينة. يستخدم معرّف Web Analytics الرسمي الموجود ويحافظ على تاريخه. يبقى الحقن التلقائي معطّلًا، ويتوقف المحمّل إذا وجد beacon سابقًا. لا عداد آخر أو إرسال يدوي أو مؤقت أو أحداث أزرار/أقسام؛ spa=false. التحديث الكامل قد يُحسب مشاهدة وزيارة إضافية بتعريف Cloudflare ولا يعني شخصًا جديدًا.

## التقارير

scripts/analytics-report.mjs يولد استعلام قراءة محصورًا بالمضيف ومعرّف المصدر، ويجمع يوم Asia/Aden من ٢١:٠٠ UTC السابق حتى ٢١:٠٠ التالي بنهاية مستبعدة. يميز الزيارات ومشاهدات المتصفح وطلبات الخادم، ويترك الأشخاص الفريدين غير متاحين؛ لا يجمع هذه المقاييس. غياب المصدر أو السجلات لا يتحول إلى صفر. هذا إعداد التقارير، لا تعديل للمنطقة الزمنية في لوحة Cloudflare ولا مهمة دورية جديدة.

## التحقق قبل النشر

نجحت ٢٧ تجربة على مصدر الإنتاج المحدد، منها منع التشغيل في المعاينات والتضمين المكرر وحدود يوم اليمن، مع اختبارات الطقس والبطاقة والنجوم والزلازل الموجودة. نجح wrangler deploy --dry-run باستخدام الإصدار المثبت 4.151.3 وتجهيز ٣٧ أصلًا. هذا بناء تجريبي فقط؛ يُثبت النشر لاحقًا من Cloudflare Builds ووصول بيانات المتصفح الفعلية.

wrangler.jsonc وWorkers جلب الطقس والإشعارات والبطاقة والصلاة والزلازل باقية دون تغيير. مفاتيح الإنتاج لم تُقرأ ولم تُنسخ؛ الربط والجدول والمستلمون لم يتغيروا. لا اختبار إرسال ولا ترقية خطة.

## التحقق بعد النشر والرجوع

يُراجع نجاح بناء commit المعتمد، ثم ظهور beacon واحد بالمعرّف الرسمي في المتصفح وسجل فتح/تحديث ضمن مصدره، مع بقاء بيانات المعاينة منفصلة. تُفحص الأقسام والبطاقة والإشعارات بالقراءة فقط. تُحفظ نتائج الفحص في تقرير متابعة مستقل لتجنب بناء إنتاج ثانٍ لمجرد توثيق النتيجة.

عند الحاجة يُعكس إصلاح الإحصاءات وحده عبر مسار GitHub المعتمد بعد الرجوع للمالك؛ الفرع الاحتياطي ونسخة Worker الثابتة يحددان السابق. لا تُصفّر الإحصاءات ولا يُحذف مصدرها. آخر سجل تاريخي مثبت قبل الإصلاح كان ١٧ أكتوبر؛ لا تثبت تلك الساعة لحظة التعطيل. لا تُسترجع مشاهدات لم تُرسل، ولا تُملأ الفجوة بتقديرات أو بطلبات الخادم.
