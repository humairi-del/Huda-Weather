# طقس هدى — نسخة الموقع المنشور v3

فرع sync-live-v3 هو توثيق مطابق لملفات العامل المنشور، دون نشر أو دمج.

## المجلدات المعتمدة لهذه النسخة
- public/: ملفات الواجهة والصور الـ28، كما استخرجت من العامل دون تغيير محتواها.
- workers/: ملفات العامل الخمسة، دون تغيير محتواها. المدخل workers/rain-entry.js؛ يستورد worker.js وrain-consensus.js، ويستورد worker.js بدوره imd-fixed.js وnotifications.js.
- reference/live-v3/: معلومات النشر، الإعدادات المقروءة، بصمات كل ملف، ونتيجة التحقق.

العامل المنشور يحتوي موارد الواجهة مضمنة داخل worker.js. مجلد public هو تمثيل مقروء مطابق لهذه الموارد وليس إضافة لربط ASSETS جديد. لا تفترض أن تعديل public وحده يعدل الموارد المضمنة. التعديل وإعادة البناء عمل لاحق يحتاج مراجعة مستقلة.

أُنشئ هذا الفرع من main عند e89bed0cc4a1fe77d88f8e892d832df9be8bd890. بقيت الملفات القديمة في جذر المستودع كما هي، دون حذف أو نقل؛ index.html وsw.js الموجودان في الجذر تابعان للنسخة القديمة وليسا مدخل v3. ملفات v3 المعتمدة في public وworkers فقط. لا تنشر جذر هذا الفرع مباشرة.

## مرجع المطابقة
- الخدمة: hada-weather-web-v3؛ النطاق: https://hada-weather.com
- النشر: 270ff522-b653-4694-ac81-e8c10301a1f7
- الإصدار: 0e86a8be-7171-4d09-83bc-5c4eb2e2bda2
- تاريخ النشر: 18 أكتوبر 2026، الساعة 8:58 مساءً بتوقيت اليمن.
- النسخة المرجعية: 20 أكتوبر 2026. أعيد التحقق من بقاء الإصدار نفسه قبل إعداد هذا الفرع.
- ملف files-sha256.json يثبت مطابقة 33 ملفًا للنسخة المرجعية، وverification.json يوثق الروابط والصياغة.

المطابقة هنا مطابقة ملفات، وليست ضمانًا لخلو الموقع الأصلي من الأخطاء أو لتوفر المصادر الخارجية. لم تُشغّل الجدولة أو الإشعارات ضمن التحقق. مسارات /api/ تعتمد على العامل، ولا تعمل بمجرد فتح HTML أو استضافة public كصفحات ثابتة.

## الإعدادات وحدود النسخة
لم تُدرج قيم الأسرار، وهي باقية في Cloudflare. runtime-settings.json يوثق أسماء الربط وأنواعه والجدولة وKV والتوافق فقط. بيانات KV نفسها غير منسوخة. لا تنقل أو تستبدل هذه الإعدادات في الإنتاج ضمن هذه الخطوة.

لا توجد إضافة لمسار نشر آلي أو Workflow، ولا ملف إعداد جاهز لنشر الخدمة الحقيقية. هذه الخطوة مزامنة مرجعية فقط؛ main والموقع المنشور دون تغيير. أي دمج أو نشر يتطلب موافقة مستقلة.
