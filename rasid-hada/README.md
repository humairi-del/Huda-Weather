# راصد هدى الذكي — Private Training

نسخة التطوير الخاصة براصد هدى الذكي. لا يتم دمجها إلى main قبل الاختبار والاعتماد.

## قواعد المعرفة
- المالك: اعتماد/رفض/تعديل المعلومات.
- خمسة معلّمين موثوقين: إضافة وتصحيح معلومات هدى.
- الزائر: اقتراح فقط، ولا يغيّر المعرفة المعتمدة مباشرة.
- كل تعديل يحتفظ بسجل تدقيق.
- المعلومات الحية مثل الطقس لا تُخزن كحقيقة دائمة؛ تُجلب من أدوات البيانات الحية.
- الحد الافتراضي للزائر عند الإطلاق العام: 10 رسائل يومياً، قابل للتعديل من الإدارة.

## الأمان
- لا مفاتيح API في الواجهة أو المستودع.
- الأسرار عبر متغيرات البيئة فقط.
- Rate limiting وحدود استخدام وميزانية.
- فصل كامل بين المعرفة المعتمدة والاقتراحات.
