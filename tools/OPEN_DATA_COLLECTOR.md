# المجمّع المفتوح التجريبي

هذا برنامج مستقل للتطوير، لا يستعمل خادم Open-Meteo المجاني ولا يغير الواجهة أو عامل الخريطة أو الإشعارات. يجمع الملفات الخام للموديلات الأربعة عند هدى وحبان، والغبار لفترة ٤٨ ساعة. شبكة المحافظة وبحر العرب وAIFS ليست مدمجة في هذه النسخة.

## التشغيل للمتابعة التقنية

استخدم بيئة Python منفصلة وثبّت `tools/open-data-requirements.txt`، ثم:

```bash
python tools/open_data_collect.py --output /tmp/hada-open-data-candidate.json
python -m unittest discover -s tools -p test_open_data_collect.py -v
```

الملف الناتج مرشح تجريبي دائمًا، و`readyForSite=false`. لا يسمح البرنامج بإخراج اسمه `latest.json` أو `index.html`. لا توجد جدولة أو عملية نشر أو مفاتيح داخل البرنامج. وجود JSON لا يعني نجاح كل المصادر؛ اقرأ `errors` وحالة كل نموذج والغبار.

## التوقيت والدقة

- الأسبوع يبدأ غدًا عند منتصف الليل بتوقيت اليمن وينتهي بعد ١٦٨ ساعة، مع نهاية حصرية.
- يقرأ آخر تشغيل منشور، ويبحث أيضًا عن تشغيل ٠٠/١٢ ذا أفق أطول إذا كان آخر تشغيل قصيرًا. يحتفظ باسم التشغيل ونهاية مدته وبصمة ملف الوصف.
- لكل ملف مصفوفة أوقات ووحدة ومرجع تشغيل وإحداثيات، وهذه هي المرجع الفعلي. وصف النموذج العام قد يذكر اتحاد أوقات جميع المتغيرات؛ لا يصح فرضه على كل متغير.
- يرفض اختلاف وحدات الملفات أو تشغيلاتها، ويحفظ القيمة الناقصة `null`، ولا يحولها إلى صفر.
- المطر مقدار الفترة الأصلية السابقة، وليس مجموعًا تراكميًا يُجمع مرة أخرى. إذا عبرت الفترة منتصف ليل اليمن، يقسم المقدار بالتناسب مع الزمن مع وسم `estimatedBoundary=true` و`uniform-within-native-interval`. هذا تقدير لتوزيع المطر بين اليومين، لا تحديد لتوقيت الهطول داخلهما. اليوم غير المغطى بالكامل يعرض مطره `null`.
- الحرارة والرياح قيم ودرجات قصوى/دنيا من العينات الأصلية؛ لا يدعي البرنامج مطابقة التطرف الحقيقي أو المعالجة الساعية في API. سرعة الرياح تُحوَّل من م/ث إلى كم/س.
- الغبار يحافظ على الفاصل الأصلي (٣ ساعات في الملف المفحوص) ويحتفظ بعينتين تحيطان بحدود فترة ٤٨ ساعة. اكتمال الفترة لا يعني وجود ٤٩ قراءة ساعية.
- لا يصنع نسبة احتمال مطر من مقدار حتمي؛ `rainProbabilityPercent=null` حتى يتوفر مصدر احتمالات مناسب.
- اختيار أقرب خلية شبكة ظاهر في كل سلسلة؛ لم تُطبق معالجة ارتفاع أو استيفاء مكاني.

## الموارد والسلامة التشغيلية

يقرأ مقاطع HTTP Range محدودة مع مخبأ، ويتحقق من Content-Range وETag. توجد ميزانية حجز ٣٢ ميغابايت و١٠٢٤ محاولة وموعد نهائي ١٠ دقائق، ومهلة ٢٥ ثانية للطلب. الحجز حد محافظ، وليس قياس التنزيل الفعلي. `rangeBytes` يجمع المقاطع للمصادر التي اكتملت؛ لا يشمل رؤوس HTTP أو تنزيلات مصادر فشلت قبل إرجاع نتيجتها.

بعض ملفات ICON المنشورة أعادت 404 على HEAD بينما نجح GET لنفس العنوان بطلب بايت واحد. توجد محاولة GET محدودة واحدة لهذا المورد نفسه قبل اعتبار حجمه غير متاح؛ لا تجاوز للحدود ولا تغيير لمسار الشبكة.

لا تشغّل الجمع عند كل زيارة للموقع. قبل أي ربط لاحق يلزم تقييم مدة الجمع وموارده، وتوفير حفظ لآخر نتيجة معتمدة وفحص عمرها، ومعالجة نقص أفق ICON ونسب الاحتمالات وAIFS وشبكة المحافظة. وجود الراعي يتوافق مع مسار البيانات المرخصة CC BY 4.0 مع نسبة المصدر والتعديلات، لكنه لا يبرر إعادة استعمال Free API الإعلاني.
