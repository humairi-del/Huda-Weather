# AIFS وشبكة الخريطة — تجربة مستقلة

هذه الأدوات تكمل المجمّع المفتوح المحلي. لا تغيّر مصدر المعاينة أو الموقع العام، ولا تضيف جدولة أو إشعارات. كل النتائج تحمل experimental=true وreadyForSite=false.

## خطوات المتابعة التقنية

تُستخدم بيئتان Python منفصلتان بمتطلبات tools/open-data-requirements.txt وtools/aifs-requirements.txt. بعد تشغيل المجمّع المحلي يمكن تشغيل:

```bash
python tools/open_data_aifs.py --output /tmp/aifs-candidate.json
python tools/open_data_map.py --output /tmp/region-candidate.json
python tools/open_data_aifs_map.py --base /tmp/region-candidate.json --local-aifs /tmp/aifs-candidate.json --output /tmp/combined-candidate.json
python -m unittest discover -s tools -p 'test_open_data*.py' -v
```

الأوامر لا تتصل بحساب خاص أو تطلب مفتاحًا. لا تكتب إلى latest.json، ولا تشغّل أدوات الجمع عند كل زيارة.

## مصدر AIFS

ECMWF AIFS ENS من أرشيف dynamical.org، ترخيص CC BY 4.0 مع شروط ECMWF والنسب إلى المعالج والمصدر. تُقرأ بيانات Icechunk/Zarr المتاحة للعامة، باستخدام جلسة للقراءة فقط. يحفظ الجمع المحلي رقم لقطة الأرشيف والتشغيل؛ جمع الشبكة يثبت اللقطة نفسها والتشغيل نفسه لتجنب اختلاف التشغيل بين النقطتين والخريطة.

تُشترط الأعضاء ٠–٥٠ جميعًا والوحدات والفاصل الأصلي ٦ ساعات. المطر في المصدر معدل متوسط للفترة السابقة بوحدة kg/m²/s، المكافئة ملم/ثانية. يُضرب في طول الفترة لاستخراج ملم. قيمة المطر عند بداية التشغيل مفقودة بطبيعتها ولا تُعامل كصفر مرصود. أي عضو مفقود ضمن الفترة المطلوبة يرفض النتيجة؛ لا متوسط يتجاهل الأعضاء الناقصة.

## معنى الاحتمالات

- احتمال الفترة الأصلية: نسبة الأعضاء الـ٥١ التي تتوقع أكثر من ٠٫١ ملم خلال ٦ ساعات.
- الاحتمال اليومي: نسبة الأعضاء التي يزيد مجموعها اليومي المقدر حسب أيام اليمن على ٠٫١ ملم. تقسم الفترات التي تعبر منتصف الليل بالتناسب مع الزمن، ويُصرّح أنه تقدير.
- المقارنة بالحد تُجرى قبل تقريب الأرقام، لمنع تغيير تصنيف العضو القريب من ٠٫١ ملم.
- هذان التعريفان لا يساويان أعلى احتمال ساعي في البطاقة الحالية. لا تُستبدل النسبة القديمة بهما دون تعديل تسمية الفترة وشرحها واختبار الواجهة.
- تطرف الحرارة والرياح: متوسط أقصى/أدنى العينات لكل عضو، من بيانات ٦ ساعات؛ ليس تطرفًا ساعيًا كاملًا.

## شبكة الخريطة

٤٢٥ خلية بحدود 42–60 شرقًا و9–21 شمالًا وخطوة 0.75 درجة، و٣ نقاط محلية مرجعية. ملخص محافظة شبوة مستخرج من الخلايا الواقعة داخل حدود المحافظة الفعلية مع استبعاد ثقوب المضلع، وليس من عتق وحدها. الشبكة خشنة؛ لا تُعرض أرقامها كتوقع لكل قرية أو تكامل مساحي للمحافظة.

كل نموذج يعطي مجموع أسبوع كامل أو يُستبعد من الوسيط في تلك الخلية. لا يُملأ نقص اليوم الأخير في ICON من نموذج آخر، ولا يتغير موعد الأسبوع. متوسط الأعضاء الـ٥١ لـAIFS يُعد نموذجًا واحدًا فقط. الوسيط النهائي محسوب بين النماذج المكتملة؛ لا وزن إضافيًا لـAIFS بعدد أعضائه.

قائمة models توضح المصادر التي قُرئت، وcount وtotals داخل كل خلية يوضحان المصادر التي دخلت المجموع فعلًا. completeGridFourModels يعني اكتمال الموديلات الحتمية الأربعة الأصلية؛ completeGridAtLeastFourModels يعني وجود أربعة مصادر مكتملة بعد إضافة AIFS؛ completeGridFiveModels يعني اكتمال الخمسة جميعًا. لا تخلط هذه الحالات في عنوان الصورة أو مفتاحها.

## القياس والقيود

تُقاس مقاطع OM الفعلية منفصلة عن بافرات Zarr المنطقية المضغوطة. قياس encodedZarrBytesDelivered ليس قياسًا لكل مرور HTTP أو إعادة المحاولة أو تثبيت المكتبات. لا تجمع المقياسين ثم تعلن تكلفة نقل دقيقة.

القراءة الإقليمية لـOM محدودة بحجز 128 MiB و٤٠٩٦ محاولة و١٥ دقيقة. قراءة Zarr تختار تشغيلًا واحدًا ونقاط الشبكة فقط، بحد مراقبة 128 MiB للبيانات المنطقية المعادة؛ ليس هذا حدًا على كل نقل HTTP في عميل Icechunk. حدود الذاكرة والنقل الفعلي وتوافر التشغيل الدوري تحتاج قياسًا في بيئة التشغيل المختارة قبل الوعد بتكلفة صفرية أو الاعتماد العام.

لا مسار لمركز الحالة مستخرج من المطر. track=null. لا قراءة CAPE أو مدى الرؤية أو كل وظائف الطقس العام في هذه الإضافة؛ تبقى مراجعة توافق حقول الواجهة مطلوبة قبل استبدال المصدر الحالي.
